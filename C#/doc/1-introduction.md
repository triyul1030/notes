## Notes

* C# dibaca “C-Sharp”
* Bahasa pemrograman object-oriented buatan Microsoft
* Berjalan di atas .NET Framework
* C# berasal dari keluarga bahasa C
  
* Mirip dengan:
  * C++
  * Java

* Versi pertama dirilis tahun 2002
  
* Versi terbaru:
  * C# 13
  * Dirilis November 2024

* Penggunaan C#:
  * Mobile applications
  * Desktop applications
  * Web applications
  * Web services
  * Web sites
  * Games
  * VR
  * Database applications

* Alasan menggunakan C#:
  * Salah satu bahasa pemrograman paling populer
  * Mudah dipelajari dan digunakan
  * Memiliki community support besar
  * Mendukung code reuse melalui object-oriented programming
  * Mengurangi development costs
  * Mudah dipelajari bagi programmer C, C++, dan Java

## Summary

* C# adalah bahasa pemrograman object-oriented buatan Microsoft yang berjalan di .NET Framework, digunakan untuk berbagai jenis aplikasi, mudah dipelajari, populer, dan memiliki kemiripan dengan C, C++, serta Java.
