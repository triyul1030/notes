## Notes

* COBOL = Common Business Oriented Language
* Dikembangkan oleh CODASYL (Conference on Data Systems Language)
* Dibuat untuk business data processing
* Tidak digunakan untuk system software

* Digunakan pada:
  * Defense domain
  * Insurance domain
  * Banking
  * Government
  * Healthcare
  * Retail

* COBOL adalah high-level programming language
* Syntax mirip bahasa Inggris (English-like syntax)

* Fokus pada:
  * Data processing
  * File handling
  * Transaction processing

* Dapat berjalan di:
  * Mainframes
  * Windows
  * Linux
  * Unix
  * Cloud environments

* COBOL masih relevan:
  * Banyak legacy systems masih menggunakan COBOL
  * Digunakan untuk payroll, transaction processing, batch processing
  * Penting di banking, finance, insurance, government

* COBOL modern:
  * Mendukung structured programming
  * Mendukung object-oriented programming
  
  * Integrasi dengan:
    * APIs
    * Web services
    * Databases
  
  * Mendukung interoperability dengan bahasa lain

* Alasan belajar COBOL:
  * Masih banyak digunakan
  * Dibutuhkan untuk maintenance & modernization legacy systems
  * Membuka peluang kerja

* Features COBOL:
  * English-like syntax
  * User friendly
  * Self-documenting language
  * Mendukung huge data processing
  * Strong file handling
  * Compatible dengan versi sebelumnya
  * Effective error messages
  * Structured language
  * Banyak debugging & testing tools

* Struktur dasar program COBOL:
  * IDENTIFICATION DIVISION
  * ENVIRONMENT DIVISION
  * DATA DIVISION
  * PROCEDURE DIVISION

* Cara kerja compiler:
  * Source code dijalankan melalui compiler
  * Compiler cek syntax errors
  * Compiler mengubah code menjadi machine language
  * Output disebut load module

* Evolution of COBOL:
  * 1959: COBOL dikembangkan oleh CODASYL
  * 1961: COBOL-61
  * 1968: COBOL-68 (ANSI standard)
  * 1974: COBOL-74
  * 1985: COBOL-85
  * 2002: Object-Oriented COBOL

## Summary

* COBOL adalah bahasa pemrograman high-level yang dibuat untuk business data processing dengan syntax mirip bahasa Inggris, masih banyak digunakan pada legacy systems di sektor bisnis dan pemerintahan, serta terus berkembang dengan dukungan modern seperti object-oriented programming dan integrasi dengan teknologi terbaru.
