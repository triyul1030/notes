## Notes

* Java adalah bahasa pemrograman populer dan powerful
* Dibuat tahun 1995
* Dimiliki oleh Oracle
* Lebih dari 3 miliar device menjalankan Java

* Penggunaan Java:
  * Mobile applications (khususnya Android)
  * Desktop applications
  * Web applications
  * Web servers dan application servers
  * Games
  * Database connection

* Java dapat berjalan di berbagai platform:
  * Windows
  * Mac
  * Linux
  * Raspberry Pi

* Alasan menggunakan Java:
  * Salah satu bahasa pemrograman paling populer
  * Banyak dibutuhkan di job market
  * Mudah dipelajari dan digunakan
  * Open-source dan gratis
  * Secure, fast, dan powerful
  * Memiliki community support besar
  * Mendukung code reuse melalui object-oriented programming
  * Mudah dipelajari bagi programmer C++ dan C#

* Java adalah object-oriented language
* Memberikan struktur program yang jelas
* Membantu menurunkan development costs

## Summary

* Java adalah bahasa pemrograman object-oriented yang populer, powerful, dan multiplatform, digunakan untuk berbagai jenis aplikasi seperti Android, web, dan desktop, serta dikenal karena mudah dipelajari, aman, dan memiliki dukungan komunitas yang besar.
