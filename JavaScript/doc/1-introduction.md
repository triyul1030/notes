# Introduction

## Cue

* Fungsi JavaScript
* JavaScript sebagai bahasa web
* Manipulasi HTML & CSS
* Mengubah HTML content
* Mengubah HTML attributes
* Mengubah style CSS
* Menyembunyikan & menampilkan element
* getElementById()
* Perbedaan JavaScript dan Java
* Brendan Eich & ECMAScript

## Notes

* JavaScript adalah programming language untuk web

* JavaScript dapat:
  * Calculate data
  * Manipulate data
  * Validate data
  * Update HTML
  * Change HTML
  * Change CSS

* Mengubah HTML Content:
  * Menggunakan method:
    * getElementById()
  
  * Mengubah:
    * innerHTML

  * Contoh:
    * `document.getElementById("demo").innerHTML = "Hello JavaScript";`

* JavaScript menerima:
  * Double quotes
  * Single quotes

* Mengubah HTML Attribute Values:
  * Dapat mengubah attribute seperti:
    * src pada tag `<img>`

* Mengubah HTML Styles (CSS):
  * Mengubah style element HTML
  
  * Contoh:
    * `style.fontSize = "35px"`

* Menyembunyikan HTML Elements:
  * Menggunakan:
    * `style.display = "none"`

* Menampilkan HTML Elements:
  * Menggunakan:
    * `style.display = "block"`

* JavaScript dan Java berbeda:
  * Berbeda konsep
  * Berbeda design

* JavaScript:
  * Dibuat oleh Brendan Eich tahun 1995
  * Menjadi standar ECMA tahun 1997
  * ECMA-262 = nama resmi standar
  * ECMAScript = nama resmi bahasa

## Summary

* JavaScript adalah bahasa pemrograman web yang digunakan untuk memanipulasi data, HTML, dan CSS, termasuk mengubah content, style, dan element pada halaman web, serta merupakan bahasa yang berbeda dari Java dan distandarisasi sebagai ECMAScript.
