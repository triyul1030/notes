## Notes

* React adalah front-end JavaScript library
* React dikembangkan oleh Facebook Software Engineer Jordan Walke

* React juga dikenal sebagai:
  * React.js
  * ReactJS

* React digunakan untuk membangun UI components

* Cara kerja React:
  * React membuat VIRTUAL DOM di memory
  * Tidak langsung memanipulasi browser DOM
  * Manipulasi dilakukan di virtual DOM terlebih dahulu
  * Setelah itu perubahan diterapkan ke browser DOM
  * React hanya mengubah bagian yang perlu diubah

* Sebelum belajar React perlu memahami:
  * HTML
  * CSS
  * JavaScript

* React.JS History:
  * Pertama digunakan tahun 2011 pada Facebook Newsfeed
  
  * Initial public release:
    * Version 0.3.0
    * Juli 2013

  * Latest version:
    * React 19.0.0
    * Desember 2024

## Summary

* React adalah front-end JavaScript library yang dibuat oleh Jordan Walke untuk membangun UI components menggunakan konsep Virtual DOM agar perubahan pada halaman web lebih efisien dan hanya memperbarui bagian yang diperlukan.
