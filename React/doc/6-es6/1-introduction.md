## Notes

* ES6 = ECMAScript 6
* ECMAScript dibuat untuk standardisasi JavaScript
* ES6 adalah versi ke-6 dari ECMAScript
* Dipublikasikan tahun 2015
* ES6 juga dikenal sebagai:

    ```js id="7l0n1w"
    ECMAScript 2015
    ```

* React menggunakan ES6
* Perlu memahami beberapa fitur ES6

* Fitur ES6:
  * Classes
  * Arrow Functions
  * Variables:

    ```js id="g5b7tc"
    let
    const
    var
    ```

  * Array Methods:

    ```js id="u6v1de"
    .map()
    ```

  * Destructuring
  * Modules
  * Ternary Operator
  * Spread Operator

## Summary

* ES6 atau ECMAScript 2015 adalah versi ke-6 ECMAScript yang dibuat untuk standardisasi JavaScript, dan menjadi dasar penting dalam React dengan fitur seperti classes, arrow functions, destructuring, modules, dan spread operator.
