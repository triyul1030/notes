# Getting Started

## Cue

* Persiapan menggunakan React
* Node.js dan npm
* React Environment
* Build tool (Vite)
* Install Vite
* Membuat React application
* Install dependencies
* Menjalankan React app
* localhost:5173

## Notes

* Untuk menggunakan React di production:
  * Membutuhkan npm
  * npm sudah termasuk dalam Node.js
  * Perlu setup React Environment
  * Perlu memilih build tool

* Cek instalasi Node.js:
  * Command:
    * `node -v`
  
  * Jika berhasil:
    * menampilkan versi Node.js
  
    * contoh:
      * `v22.15.0`

* Build tool yang digunakan:
  * Vite

* Install Vite:
  * Command:
    * `npm install -g create-vite`

* Membuat React application:
  * Command:
    * `npm create vite@latest my-react-app -- --template react`

* Jika muncul prompt:
  * `Ok to proceed? (y)`
  * Tekan:
    * `y`
    * Enter

* Setelah project dibuat:
  * Masuk ke folder project:
    * `cd my-react-app`

* Install dependencies:
  * Command:
    * `npm install`

* Menjalankan React application:
  * Command:
    * `npm run dev`

* Jika berhasil:
  * Vite server berjalan
  * Menampilkan:
    * `http://localhost:5173/`

* React app akan terbuka di browser

* Jika tidak otomatis:
  * buka browser
  * akses:
    * `localhost:5173`

## Summary

* Untuk mulai menggunakan React, perlu menginstall Node.js dan npm, menggunakan Vite sebagai build tool, membuat project React, menginstall dependencies, lalu menjalankan aplikasi dengan `npm run dev` melalui localhost.
